# girishjainrealtor.com

Single-page static website for Girish Jain, REALTOR® with Tesla Realty Group (Media, PA), hosted on Netlify (project "glowing-panda-0a0726") and deployed automatically from this repository's `main` branch.

- `index.html` — the site (one page; the hero photo is embedded as data)
- `thanks.html` — thank-you page shown after a lead form is submitted

Lead forms ("hero-lead" and "contact") are wired to Netlify Forms; submissions email girishjainrealtor@gmail.com and are logged in the "Netlify Leads" Google Sheet.
